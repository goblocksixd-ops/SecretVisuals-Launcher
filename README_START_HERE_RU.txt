SECRET VISUALS LAUNCHER SV34

1) Распакуй весь архив в отдельную папку.
2) Запусти INSTALL_AND_RUN.bat.
3) Главная — первая вкладка. Тарифы — вторая.
4) В каталоге модов просто начни вводить название: поиск запускается автоматически. Кнопка «Найти» больше не нужна.

Нужен Node.js LTS. CurseForge открывается в браузере; встроенный поиск работает через Modrinth.
