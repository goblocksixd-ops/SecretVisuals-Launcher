SECRET VISUALS LAUNCHER — ОБНОВЛЕНИЕ ДИЗАЙНА

Запуск: установите Node.js LTS с https://nodejs.org/, затем дважды нажмите START_LAUNCHER.bat.
При первом запуске будет выполнен npm install; требуется интернет.

Окно сделано в пропорциях референса (759x455), без системной рамки, с узкой левой панелью и тремя карточками:
FREE — Minecraft 1.16.5
BASIC — Minecraft 1.21.4
PREMIUM — Minecraft 1.21.11

Важно: это UI-проект. Кнопки карточек пока не скачивают и не запускают Minecraft. Тариф в настройках хранится локально и НЕ является серверной проверкой лицензии.


Minecraft: вход выполняется через Microsoft. Для запуска требуется аккаунт, владеющий Minecraft: Java Edition, и интернет для первой загрузки файлов. Нажми «Войти Microsoft», затем выбери карточку версии. Java 21 требуется для 1.21.x; Java 8 — для 1.16.5. Запуск игры на этой сборке автоматически не проверен.
