# SecretVisuals Launcher SV34 — Auto Search + Tabs

Изменения:
- Главная вкладка с версиями Minecraft открывается первой.
- «Тарифы» перенесены на вторую кнопку бокового меню.
- Каталог Modrinth начинает искать автоматически после ввода текста (пауза 350 мс); кнопка «Найти» больше не нужна.
- Enter по-прежнему запускает поиск немедленно.
- При смене источника каталог обновляется автоматически, если запрос уже введён.
- Сохранены серая тема, карточки версий, настройки и текущая структура запуска.

## Запуск
1. Распакуйте архив полностью в отдельную папку.
2. Запустите `INSTALL_AND_RUN.bat`.
3. Нужен Node.js LTS.

Примечание: интеграция CurseForge открывает результаты на официальном сайте в браузере; встроенный поиск и установка модов реализованы через Modrinth. Запуск Minecraft зависит от входа в Microsoft и совместимости текущего окружения.


## Тестовые ключи тарифов (SV36)
- BASIC: `SV-BASIC-7K4P-9X2M` — Minecraft 1.21.4.
- PREMIUM: `SV-VIP-8N5Q-3L7R` — Minecraft 1.21.11.
- FREE доступен без ключа — Minecraft 1.16.5.

Важно: эти ключи активируются локально в этой сборке для проверки интерфейса. Это не серверная лицензия и не подтверждение оплаты; для настоящих продаж проверку нужно вынести на сервер.
